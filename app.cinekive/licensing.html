Licensing

Cinekive Archive is a public, read-only inspiration gallery of real stills (photographed or otherwise licensed). It is a companion to the Cinekive desktop app — not a substitute for it. AI is used only to categorize and tag craft (camera, lens, lighting, mood), not to generate images.

Catalog model

All stills ship in a static frames.json file maintained in the repo (edited via PR). There is no visitor upload path. Each entry must include a non-empty source and license. Entries missing either field are skipped at load time and warned in the browser console.

  • Source is shown on every card so credit stays visible.
  • License appears in the card overlay with the AI tags.
  • We do not claim ownership of third-party stills in this public archive.

Local lists

Favorites and custom lists are stored only in your browser (IndexedDB). Nothing is synced to a server. Export/import JSON is the supported way to move lists between devices.

Sample / demo content

Demo frames shipped with this site use Unsplash photographs under the Unsplash License, with photographer credit in the source field. Replace them with cleared rights before a production deploy.

What this site does not do

  • No uploads from visitors
  • No user accounts or cloud sync
  • No desktop ingest / moodboard features (use the free Cinekive desktop app)

Takedown

If you believe a still is listed without a proper grant, email cinekive@agentmail.to with the frame id, source URL, and your claim. We will remove or correct it.
